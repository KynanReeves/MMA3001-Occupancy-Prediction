# MMA3001 Smart Infrastructure Occupancy Prediction

## Overview

This project investigates whether environmental sensor measurements can be used to predict occupancy within smart building environments.

The work is completed as part of MMA3001 Numerical Methods and Machine Learning at Monash University.

## Engineering Problem

Building occupancy information is useful for:

- HVAC control
- Energy optimisation
- Building management
- Comfort monitoring

This project evaluates machine learning models for occupancy prediction using environmental sensor measurements.
